# 2. 제안 시스템

## 2.1 시스템 구성

제안하는 취득 시스템은 로봇 주행 방향 중앙의 수직 지주(알루미늄 프로파일)에 4대의 RGB 카메라(Logitech BRIO)를 좌·우 각 2대씩 배치하여 구성된다. 각 면의 두 카메라는 통로 양쪽의 재배 라인을 향하며, 위쪽 카메라는 약 45° 하향으로, 아래쪽 카메라는 약 45° 상향으로 동일한 라인을 위·아래 두 각도에서 관측한다. 이를 통해 위에서 잎에 가려진 과실을 아래 시점이 보완하는 방식으로 가림을 완화한다. 좌·우 면은 서로 반대 방향의 재배 라인을 담당한다. 각 카메라는 1280×720 해상도의 MJPG 스트림을 출력하며, USB를 통해 하나의 소형 PC(NUC)에 연결된다. 4대를 단일 호스트에 통합함으로써 카메라 간 시간 기준을 동일한 시스템 시계로 공유할 수 있으며, 별도의 외부 하드웨어 트리거 장치 없이 소프트웨어 수준에서 동기 취득을 수행한다. ## 2.2 시간 동기화

다중 카메라를 각각 독립적으로 구동하여 저장하는 단순한 방식에서는, 카메라마다 캡처 루프의 시작 시점과 주기가 미세하게 달라 동일한 시간 구간을 촬영하더라도 카메라별로 저장되는 프레임 수가 어긋나며, 같은 순번의 프레임이 동일한 순간에 취득되었다는 보장도 없다 [n]. 이러한 문제를 해소하기 위해 본 시스템은 취득과 저장의 역할을 분리한다.

구체적으로, 데이터를 생성하는 주체와 소비하는 주체를 분리하는 생산자-소비자(producer–consumer) 패턴 [n]을 적용한다. 각 카메라는 독립적인 producer 스레드에서 프레임을 연속적으로 취득하며, 캡처 직후의 시각과 함께 자신의 최신 프레임을 공유 버퍼의 해당 슬롯에 덮어쓴다. 이때 시스템 시간 보정의 영향을 받지 않도록 단조 증가 시계(monotonic clock)를 기준 시각으로 사용하며, producer는 디스크 저장을 수행하지 않는다. 한편 단일 consumer(매처)는 일정 주기마다 한 번씩 네 슬롯을 동시에 읽어, 그 순간의 최신 프레임 4장에 동일한 묶음 번호를 부여하여 저장한다. 저장 시점의 결정이 매처라는 단일 주체로 일원화되므로 묶음마다 항상 정확히 4장이 저장되며, 카메라 간 프레임 수 불일치가 구조적으로 제거된다.

동기화 품질을 정량화하기 위해, 한 묶음을 구성하는 네 프레임의 캡처 시각 중 최댓값과 최솟값의 차이를 동기화 오차(sync gap)로 정의한다. 이는 네 시점이 실제로 얼마나 가까운 순간에 취득되었는지를 나타낸다. 또한 매처가 슬롯을 읽은 순간을 기준으로 각 프레임의 캡처 경과 시간(age)을 함께 기록하여, 특정 카메라가 일시적으로 프레임을 갱신하지 못해 오래된 프레임이 묶음에 포함되는 경우를 검출한다. 동기화 오차의 상한은 프레임 취득 간격에 의해 결정되므로, 각 카메라에 목표 프레임레이트를 명시적으로 요청하여 취득 간격을 줄인다. 다만 요청한 프레임레이트가 실제로 반영되는지는 보장되지 않으므로, 실효 프레임레이트를 별도로 측정하여 확인한다.

## 2.3 공간 정합

다중 시점 이미지 데이터를 같은 대상의 일관된 관측으로 결합하려면, 각 카메라의 내부 파라미터(intrinsic parameter)와 카메라 간 상대 위치·자세(extrinsic parameter)를 알아야 한다. 본 시스템은 공간 정합을 두 단계로 수행한다.

먼저 각 카메라에 대해 체커보드를 여러 위치·각도로 촬영하여 초점거리, 주점, 렌즈 왜곡 계수로 구성된 내부 파라미터를 추정한다(intrinsic calibration). 이때 자동 초점 기능이 활성화되면 초점거리가 촬영 중 변동하여 내부 파라미터가 불안정해지므로, 초점을 고정한 상태로 촬영하여 파라미터의 일관성을 확보한다.

다음으로 같은 면(좌 또는 우)에 배치된 두 카메라의 상대 자세를 산출한다. 두 카메라가 동일한 체커보드를 동시에 관측한 이미지 쌍으로부터 스테레오 보정(stereo calibration)을 수행하여, 한 카메라의 좌표계를 기준으로 다른 카메라의 회전(rotation)과 이동(translation)을 계산한다. 이 과정에서 앞서 기술한 시간 동기화를 이용하여 두 카메라가 같은 순간의 동일한 보드 자세를 포착하도록 보장함으로써, 움직이는 보드에서도 정합의 신뢰성을 확보한다. 좌·우 면은 서로 다른 재배 라인을 담당하므로, 각 면 내부(2대)의 정합만으로 해당 면의 다시점 이미지 데이터를 공통 좌표계로 정렬할 수 있다.

정합 품질은 추정된 내부·외부 파라미터로 체커보드의 3차원 격자점을 이미지 평면에 재투영했을 때 실제 검출 좌표와의 차이를 나타내는 재투영 오차(reprojection error)로 정량화한다.
