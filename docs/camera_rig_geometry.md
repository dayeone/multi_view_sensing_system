# 카메라 리그 기하 사양

무인방제 로봇(Ranger mini) 탑재 4채널 Logitech BRIO의 물리 배치와 기하 실측값.

- 실측 기준일: 2026-07-20 (내재·외재 재캘리브레이션)
- 검증일: 2026-08-07 (udev 규칙·스테레오 외재 대조)

---

## 1. 물리 배치

중앙 수직 지주에 좌·우 두 면, 각 면에 상·하 2대씩 총 4대를 장착한다.

```
        [좌면]                    [우면]
   cam2 (Left Top)           cam4 (Right Top)
      ↘ 약 45° 하향             ↘ 약 45° 하향
   ─── 재배 라인 A ───      ─── 재배 라인 B ───
      ↗ 약 45° 상향             ↗ 약 45° 상향
   cam1 (Left Bottom)        cam3 (Right Bottom)
```

- **같은 면 2대**가 같은 재배 라인을 상·하에서 관측한다.
- **좌·우 면**은 서로 다른 재배 라인을 담당한다.
- 하단 2대(`cam1`, `cam3`)는 **180° 뒤집혀 장착**되어 있다.

### 상보 관측 — 중복 관측이 아니다

같은 면 2대의 광축은 **약 90° 벌어져 있다**(180° 롤을 제거한 순수 틸트 차이).
상단은 잎 윗면, 하단은 잎 아랫면을 본다. 같은 대상을 두 번 보는 구조가 아니다.

이로부터 두 가지가 따른다.

- **카메라 간 검출 박스 병합은 물리적으로 성립하지 않는다.** 서로 다른 면을 보고 있다.
- **"카메라 간 중복 계수" 우려는 과대평가였다.** 중복 계수는 주행 중 시간축에서 발생하는 문제이지, 카메라 간 문제가 아니다.

## 2. 디바이스 매핑

udev 규칙이 카메라 시리얼로 고정 심볼릭 링크를 만든다. USB 포트 순서·재연결과 무관하게 물리 위치가 고정된다.

| 링크 | 물리 위치 | 시리얼 | 180° 플립 |
|---|---|---|---|
| `/dev/cam1` | Left Bottom | `3A51684E` | 있음 |
| `/dev/cam2` | Left Top | `1FAE2749` | 없음 |
| `/dev/cam3` | Right Bottom | `E9641DF5` | 있음 |
| `/dev/cam4` | Right Top | `FA3B02ED` | 없음 |

규칙 파일: [setup/udev/99-usb-cameras.rules](../setup/udev/99-usb-cameras.rules)

각 BRIO는 `/dev/videoN` 노드를 4개(`index` 0~3) 만들며 전부 같은 시리얼을 갖는다.
시리얼만으로 링크하면 영상이 아닌 메타데이터 노드를 잡아 흑백·깜빡임이 생기므로,
규칙에 `ATTR{index}=="0"` 조건을 함께 건다.

### 구 명명 규칙 (폐기됨)

`cam0/cam4/cam8/cam12`는 `/dev/videoN` 인덱스 기반의 옛 표기다. 2026-07-13에
`cam1~4`로 전환했다. 옛 표기를 그대로 둔 코드는 동작하지 않는다.

## 3. 180° 플립 처리 규칙

**하단 2대의 물리적 180° 회전은 스테레오 외재 파라미터에 이미 흡수되어 있다.**

실측 상대 회전: left 179.22°, right 179.92°

따라서 다음 규칙을 지킨다.

- **저장 시점에 회전을 적용하지 않는다.** 적용하면 봉인된 외재 파라미터와 어긋나 공간 정합이 깨진다.
- **회전은 추론·시각화 단계에서만 적용한다.**

## 4. 기하 실측값

| 항목 | 값 |
|---|---|
| baseline (좌면 cam1↔cam2) | 593.9 mm |
| baseline (우면 cam3↔cam4) | 587.5 mm |
| 광축 교점 거리 D₀ | 약 418 mm |
| 내재 fx 범위 | 746.7 ~ 763.0 (평균 757.5) |
| GSD (광축 교점 기준) | **0.552 mm/px** |
| GSD 범위 (프레임 내) | 0.41 ~ 1.16 mm/px |
| 프레임 내 깊이 편차 | 314 ~ 882 mm (2.8배) |

**GSD**(Ground Sampling Distance): 이미지 1픽셀이 대응하는 실제 크기.

45° 틸트로 촬영하므로 프레임 위·아래의 피사체 거리가 크게 다르다. 프레임 하나 안에서
GSD가 2.8배까지 변하므로, 병반 크기를 픽셀 수로 환산할 때는 위치별 보정이 필요하다.

## 5. 정합 오차 — 보고할 값

`cv2.stereoCalibrate()`가 반환하는 RMS는 최적화 목적함수 값이며, 실제 재투영 정합
오차보다 작게 나온다. **외부에 보고할 때는 전파 오차를 쓴다.**

| 지표 | 좌면 | 우면 |
|---|---|---|
| `stereoCalibrate` 반환 RMS | 0.372 px | — |
| **실제 전파 오차** | **1.118 px** | **1.435 px** |
